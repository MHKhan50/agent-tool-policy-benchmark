# Short publication checklist

- [ ] Run the experiment and tests on the intended Python interpreter.
- [ ] Inspect `outputs/metrics_by_seed.csv`, `outputs/metrics_summary.csv`, and `outputs/policy_comparison.svg`.
- [ ] Review at least 10 generated scenarios and confirm the action permissions are coherent.
- [ ] Add a sensitivity analysis for attack rate and confirmation accuracy.
- [ ] Replace the Results placeholder in `docs/ARTICLE_DRAFT.md` using actual exported metrics.
- [ ] Review related literature before asserting novelty; cite official university pages only for research context.
- [ ] Commit source, tests, data card, and reproducible outputs to GitHub.
- [ ] Optionally publish the synthetic CSV plus `DATA_CARD.md` on Kaggle; label it synthetic and include seed/rates.
- [ ] Consider Zenodo/OSF/Figshare for a citable version/DOI if this is a stable research artifact.
- [ ] Add the article to the website and verify both the article URL and Insights listing after deployment.
- [ ] Optionally use Google Search Console URL Inspection and request indexing; indexing is not guaranteed and is not a certificate.
